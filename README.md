# Finance Transformation Portfolio (Starter Kit)

This repo is a clean, professional portfolio tailored for a Finance Transformation leader who also showcases data/Python chops.

## What’s Inside
- **/index.html, styles.css, script.js** — static site (blue-gradient theme)
- **/projects.json** — edit your project cards here (no code changes needed)
- **/python_demos** — Streamlit app with simple finance demos you can run locally
- **/assets/logo.svg** — placeholder logo (customize later)

## Run Locally (Static Site)
Open `index.html` in your browser or use a lightweight server:

```bash
# from repo root
python -m http.server 8080
# then open http://localhost:8080
```

## Deploy to GitHub Pages
1. Create a new repo and push these files.
2. In GitHub, Settings → Pages → Build and deployment → Branch: `main` (`/root`), Save.
3. Your site will publish at: `https://<your-username>.github.io/<repo>/`.

## Python Demos (Streamlit)
See `python_demos/README_run.md` for quick-start commands to run the demo app that powers the Python sections.
